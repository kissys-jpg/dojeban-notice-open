# 도제반 알림판

경기항공고등학교 로봇자동화과 전자기기생산 L2 도제반에서 실제로 쓰는 알림·관리 웹앱의 **공개 소스**입니다.
구글 시트를 데이터베이스로, 구글 Apps Script를 서버로 써서 별도 서버 없이 돌아갑니다.

> 이 저장소는 학생들이 코드를 읽고, 자기 계정에 설치해 보고, 고쳐서 제안하기 위한 곳입니다.
> 실제 운영 중인 알림판과는 연결되어 있지 않습니다. 여기서 무엇을 바꿔도 운영 앱은 바뀌지 않습니다.

## 기능
- 오늘 화면(할 일·일정·급식), 머리글 '최근 업데이트' 표시
- 공지(대상별)·읽음 확인, 일정 달력, 방과후 시간표, 학생별 일정, 휴대폰 캘린더 구독(.ics)
- 시간표(컴시간알리미 실시간)·급식(나이스)
- 익명게시판(신고·처리 상태), 실습재료 구매요청
- 프로젝트: 공유 게시판(프로젝트·자격증·대회 일정) + 우리 팀(과제·팀 자료함)
- 도제 훈련: 훈련 기업, OJT 시간표, 훈련 출결, 능력단위 이수·평가
- 포트폴리오(노션 연결), 자료실, Drive 폴더 접근 신청
- 명단 관리(이름 수정 시 기록 연결 유지, 삭제)

## 구조
| 경로 | 내용 |
|---|---|
| `src/Code.gs` | 서버 코드. `api(req)`로 들어온 요청을 `dispatch_`에서 `action`별로 처리 |
| `src/Index.html` | 화면 전체(HTML·CSS·JS 한 파일) |
| `src/appsscript.json` | Apps Script 프로젝트 설정 |
| `sample-data/` | 가짜 학생·일정·재료 데이터(CSV) |
| `tools/check.js` | 문법, `//` 문제, 비밀값 유출 점검 |
| `tests/` | 가짜 구글 환경 + Playwright 화면 테스트 |

## 시작하기
1. **내 계정에 설치해 보기** → [`docs/직접_설치하기.md`](docs/직접_설치하기.md)
2. **고쳐서 제안하기** → [`CONTRIBUTING.md`](CONTRIBUTING.md)
3. **AI로 고치기** → [`docs/AI로_고치기.md`](docs/AI로_고치기.md)

## 점검과 테스트
```
node tools/check.js              # 문법, '//' 문제, 비밀값 유출
npm install && npx playwright install chromium
node tests/run.mjs               # 가짜 구글 환경 화면 테스트 (최신 화면에 맞추는 중)
```

## 꼭 지켜 주세요
1. 실제 학생 이름·PIN·연락처·출결을 코드·이슈·PR에 올리지 않습니다. `sample-data`의 가짜 이름만 씁니다.
2. 비밀번호·시트 ID·API 키는 코드에 적지 않고 Apps Script **스크립트 속성**에 둡니다.
3. `src/Index.html`의 `<script>` 안에서는 `//`를 쓰지 않습니다(화면이 하얗게 멈춥니다).
