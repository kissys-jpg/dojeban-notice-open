# 실습기자재 사용대장

알림판 상단 **실습기자재**(휴대폰 **기자재**)에서 물품명 **라즈베리파이**를 누르면 **라즈베리1~라즈베리14**가 펼쳐집니다.

- 체크된 번호는 사용 중이며 바로 아래에 현재 사용자 이름을 표시합니다. 로그인한 학생도 번호별 현재 사용자 이름을 볼 수 있습니다. 타인의 용도·장소·과거 이력·인증정보는 공유하지 않습니다. 손님은 접근할 수 없습니다.
- **사용 등록**에서 사용할 번호를 체크하고 사용일·용도를 입력합니다. 교사는 사용자 이름을 지정하고 학생은 본인 이름으로 등록합니다. 반납예정일·장소는 선택입니다. 사용 중인 번호는 선택할 수 없고 선택한 개수가 수량이 됩니다.
- **반납 처리**는 해당 기록의 모든 번호를 한 번에 반납합니다. 서로 다른 시점에 반납할 계획이면 처음부터 기록을 나누어 등록합니다. 반납 이력은 남고 해당 번호를 다시 사용할 수 있습니다. 반납 권한은 본인/교사로 유지합니다.
- 과거 수량만 입력한 기록은 **번호 미지정**으로 보존합니다. 실물 번호를 확인한 후 해당 기록의 **번호 지정**에서 기존 수량만큼 체크하세요. 원래 수량·사용자·날짜·용도·반납 상태는 유지하며 새 대여를 중복 생성하지 않습니다. 번호 지정 전에는 체크가 빈 번호도 사용 가능으로 확정하지 않습니다.
- 저장은 기존 연결 시트 **앱_기자재사용** 탭을 계속 씁니다. 기존 12개 열은 유지하고 13열 **기자재번호**에 선택 번호를 저장합니다. 13열이 다른 이름으로 사용 중이면 덮어쓰지 않고 오류를 표시합니다. 실제 대여 현황·기기 자산번호를 임의로 배정하지 않습니다.
- 서버 잠금 안에서 최신 수량과 번호 중복을 다시 검사하고 같은 등록 요청/반납 재시도를 중복 처리하지 않습니다. 이전 화면에서 수량만 보내는 새 등록은 새로고침/번호 선택을 안내합니다.
- 다른 기기 변경은 **새로고침**으로 확인합니다. 첫 화면에는 대장 조회를 추가하지 않으며 기자재 진입도 명단/BOM 전체를 먼저 불러오지 않습니다. 브라우저에 대장을 별도 저장하지 않습니다.

검증: `node tools/check.js`, `node tests/equipment-ledger.mjs`. 가짜 자료만으로 교사/학생 390·1280px, 번호 선택·현재사용자 표시·타인 상세 이력 제외·권한·중복번호·재고·날짜·재시도·반납 재사용·기존12열 보존/번호 지정 등을 확인합니다. 실제 학생/사용기록을 시험 등록하지 않습니다.

한국어 PR을 main에 반영한 뒤 자동 배포의 Apps Script 배포 단계 성공을 확인하고 학생 입구 app.html 버전을 맞춥니다. 공개 소스 저장소도 공식 동기화 스크립트로 맞춥니다. Apps Script 편집기를 직접 수정하지 않습니다.
