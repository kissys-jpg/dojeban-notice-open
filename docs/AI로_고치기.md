# AI(제미나이·ChatGPT)로 고치는 방법

## 기본 원칙
- AI에게 **파일 전체 + 이슈 내용 + 아래 규칙**을 함께 줍니다.
- 답으로 받은 코드는 **바뀐 부분을 직접 읽고 이해한 뒤** 붙여넣습니다.
- 붙여넣은 다음 `node tools/check.js` → 내 설치본에서 직접 눌러 보며 확인합니다.
- 실제 학생 이름이나 PIN을 AI에 붙여넣지 않습니다.

## 1. 제미나이 (교육청 구글 계정)
gemini.google.com 에 교육청 계정으로 로그인 → 파일 첨부(＋)로 `Code.gs`, `Index.html`을 올리고 아래 지시문을 붙여넣습니다.
구글 드라이브에 올려 둔 파일이면 `@Google 드라이브`로 불러와도 됩니다.

## 2. ChatGPT
새 채팅 → 파일 첨부로 두 파일을 올리고 아래 지시문을 붙여넣습니다. 학교·회사 계정이면 대화 내용이 학습에 쓰이지 않는 설정인지 선생님께 확인하세요.

## 지시문 (복사해서 [ ] 부분만 바꾸기)
```
너는 구글 Apps Script 웹앱 코드를 고치는 도우미야. 첨부한 Code.gs(서버)와 Index.html(화면)은 고등학교 도제반 알림판이야.

[고칠 내용]
이슈 #[번호]: [이슈 제목과 내용을 그대로 붙여넣기]

[반드시 지킬 규칙]
1. Index.html의 <script> 안에서는 '//'를 절대 쓰지 마. 주소는 "https:\/\/..."로, 주석은 /* */로 써. (구글이 // 뒤를 잘라내서 화면이 멈춤)
2. 서버 요청은 api({action, payload}) 하나로 들어오고 dispatch_ 함수의 switch에서 나뉘어. 새 기능은 거기에 case를 추가해.
3. 학생에게는 자기 데이터만 보내야 해. 권한 검사(need_, 이름 비교)를 지우거나 약하게 하지 마.
4. 새로 저장할 데이터가 있으면 APP_TABS에 탭을 추가해. 시트 쓰기는 withLock_ 안에서 sheet_()/append_()/writeCells_()로 해.
5. 기존 기능은 바꾸지 말고, 필요한 부분만 최소로 고쳐.
6. 답은 한국어로. 먼저 무엇을 왜 바꾸는지 3줄로 설명하고, 그다음 바뀐 함수 전체를 "어느 파일의 어느 함수를 이것으로 교체" 형식으로 보여 줘. 파일 전체를 다시 쓰지 마.
```

## 막혔을 때
- 화면이 하얗게 나온다 → `node tools/check.js` 결과부터 확인 (대부분 `//` 문제)
- "알 수 없는 요청입니다" → 화면에서 부른 action 이름이 `dispatch_`의 case와 같은지 확인
- AI 답을 이해 못하겠다 → AI에게 "이 코드가 한 줄씩 무슨 일을 하는지 설명해 줘"라고 다시 묻기
