# 내 계정에 직접 설치하기

이 저장소의 코드를 **내 구글 계정**에 설치해서 나만의 알림판을 만들고, 마음껏 고쳐 보는 방법입니다. 실제 운영 중인 알림판과는 완전히 분리되어 있어서 무엇을 바꿔도 다른 사람에게 영향이 없습니다.

준비물: 구글 계정 하나 (개인 계정, 교육청 계정 모두 가능)

## 1. 가짜 데이터 시트 만들기
1. 구글 드라이브 → 새로 만들기 → 구글 스프레드시트 → 이름 `도제반 알림판 (가짜 데이터)`
2. 이 저장소 `sample-data` 폴더의 CSV를 내려받아 각각 **파일 → 가져오기 → 업로드 → 새 시트 삽입**으로 넣고, 탭 이름을 파일 이름과 같게 바꿉니다.
   - `앱_명단.csv` → 탭 `앱_명단` (가짜 학생과 PIN)
   - `학생별_일정표.csv` → 탭 `학생별_일정표`
   - `BOM.csv` → 탭 `BOM`
3. 시트 주소에서 `/d/` 와 `/edit` 사이의 값이 **시트 ID**입니다. 복사해 둡니다.

## 2. Apps Script 프로젝트 만들기
1. [script.google.com](https://script.google.com) → **새 프로젝트** → 이름 `도제반 알림판 (내 실습용)`
2. `Code.gs`의 내용을 모두 지우고 이 저장소의 `src/Code.gs`를 붙여넣습니다.
3. 왼쪽 **파일 ＋ → HTML** → 이름 `Index` → `src/Index.html`을 붙여넣습니다.
4. 왼쪽 **서비스 ＋ → Google Sheets API → 추가** (속도 개선용)
5. 저장(Ctrl+S)

## 3. 스크립트 속성 넣기 (비밀값은 코드에 적지 않습니다)
왼쪽 톱니바퀴 **프로젝트 설정 → 스크립트 속성 → 속성 추가**

| 속성 | 값 |
|---|---|
| `SPREADSHEET_ID` | 1번에서 복사한 시트 ID |
| `TEACHER_PASSWORD` | 내가 정한 교사용 비밀번호 (실습용) |
| `NO_LOGIN_TEST_MODE` | 처음 시험할 때만 `true` (로그인 없이 교사 화면). 학생 화면을 보려면 지우거나 `false` |

## 4. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
2. 실행: **나**, 액세스: **나만** (친구에게 보여 주려면 "모든 사용자")
3. 처음에는 권한 허용 화면이 나옵니다. 내 계정이 내 시트·드라이브에 접근하는 권한이니 허용합니다.
4. 나온 웹앱 주소로 접속합니다. 고친 뒤에는 **배포 → 배포 테스트**의 주소로 바로 확인할 수 있습니다.

## 막혔을 때
- 화면이 하얗게 나온다 → `node tools/check.js`를 돌려 보세요 (대부분 `Index.html`의 `//` 문제)
- "연결된 시트가 없습니다" → 스크립트 속성 `SPREADSHEET_ID` 값을 확인
- 시간표·급식은 경기항공고 기준(컴시간알리미·나이스)으로 연결되어 있습니다. 다른 학교로 바꾸려면 `Code.gs`의 `NEIS_OFFICE_`, `NEIS_SCHOOL_`, `COMCI_SCHOOL_` 값을 고쳐 보세요.
